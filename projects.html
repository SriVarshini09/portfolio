Projects

These projects are written as systems: the problem, the design choices, the evaluation, and what it would take to run them reliably. I’m especially interested in retrieval and real-time ML where latency and cost matter.

Real-Time Video Search Platform

GitHub

A multimodal retrieval system that searches video content by combining scene segmentation with CLIP embeddings and similarity indexing.

1.2 s query latency 25 videos 380+ scene embeddings 78% boundary accuracy

Technical approach

CLIP embeddings + automated scene detection + indexed similarity search, with a React frontend for timestamped results.

Outcome

Delivered ranked timestamped results with 0.82 top-scene similarity and support for 15+ queries.

Real-Time Feature Store & ML Serving Platform

GitHub

A real-time ML platform for consistent feature serving, model deployment, and operational monitoring with automated quality checks.

5,000 events/hour 45 ms latency 3 deployed models 8 shared features

Technical approach

Feast + Kafka streaming feature pipeline, with MLflow + Kubernetes for deployment, monitoring, and retraining triggers.

Outcome

Fraud (88%), recommendation (0.76 NDCG@5), forecasting (12% MAPE) plus drift detection and automated alerts for distribution shifts.

Multi-Agent Document Intelligence System

GitHub

A multi-agent document pipeline for extraction + retrieval with RAG, packaged as a production FastAPI service.

82% extraction accuracy < 5 s processing 85% top-3 relevance -84% manual entry time

Technical approach

Multi-agent workflow with RAG over Qdrant; delivered as a FastAPI service supporting 3 document types.

Outcome

500+ chunks indexed for semantic search (85% top-3 relevance across 50 queries) with monitoring and validation pipelines for stable operation.

How to review these projects

I try to describe projects like production systems: problem framing, technical design, evaluation, and operational considerations (latency, monitoring, reproducibility).
